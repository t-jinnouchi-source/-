# 助成金作文スキル（josei-sakubun）

人材開発支援助成金の計画届に貼る「作文」＝訓練の必要性説明文を、起案・改訂・レビューするためのスキル。

```
.claude/skills/josei-sakubun/
├── SKILL.md                    エントリポイント。工程と絶対ルール
├── references/
│   ├── 01_gate.md              起案前ゲート（器・制度・語彙・連年）と質問文の実物
│   ├── 02_kouzou.md            0303ヘ(ロ) 3段構成の文型テンプレート
│   ├── 03_ng-words.md          禁止語の全リストと理由
│   ├── 04_hearing.md           先方に投げるヒアリングシート
│   ├── 05_renzoku.md           連年・複数講座・複数部門の書き分け判定
│   └── 06_kaitei-jirei.md      実案件の Before/After 差分集
├── scripts/
│   └── check_sakubun.py        機械チェック（禁止語・字数・構造・重複）
└── eval/
    ├── run_eval.sh             回帰テスト（13ケース）
    └── fixtures/               合成データ（実案件の作文は含まない）
```

## 使い方

```bash
# 単体チェック
python3 .claude/skills/josei-sakubun/scripts/check_sakubun.py \
  --file 作文_営業.txt --min 450 --max 583

# 部門別3本を同時に出すとき
python3 .claude/skills/josei-sakubun/scripts/check_sakubun.py \
  --file 作文_営業.txt --max 583 \
  --ng-extra 案件固有禁止語.txt \
  --foreign-objects 他部門の対象物語.txt \
  --cross 作文_工場.txt 作文_業務.txt --cross-mode dept

# 別会社への使い回しチェック
python3 ... --cross 他社の作文.txt --cross-mode client

# スクリプトや禁止語を更新したら
bash .claude/skills/josei-sakubun/eval/run_eval.sh
```

終了コード：`0` = 全項目 PASS ／ `1` = high の FAIL あり（不支給・否認に直結）／ `2` = medium 以下のみ

## 何を変えたか（2026年度の改訂履歴からの改善）

シーホネンス（6版）／エスリード P2（2版）／2026年4月案件（9社）の作文を突き合わせた結果、
**手戻りは内容の質ではなく、書き始める前に確定していなかったものが後から判明したことで起きていた。**

|---|---|---|---|
| 1 | 器（様式・欄・字数）未確定のまま起案 → 826字→478+379字→590字→566字→544字→583字 と6回作り直し | **Gate-A**（器が割れるまで本文を書かない）＋ 社労士への質問文テンプレ | high |
| 2 | R8.8.3改正の4日後に書いた初稿が未反映 → 同日中に全面改稿 | **Gate-B**（起案日 vs 直近改正日の突合／経過措置の確認を最初の30分で） | high |

| 4 | v3で削除した「標準化」系が最終版で復活（リグレッション） | 案件別 **禁止語台帳** ＋ 清書版にも同じ機械チェック | high |

### 検証（改善ループの結果）

実案件4本にチェッカーを当てて、既知の欠陥を検出できるかを確認した。

| ケース | 期待 | 結果 |
|---|---|---|
| シーホネンス 提案営業 最終版 | PASS | **PASS。実字数583字が納品メモ記載の「583字」と完全一致** |
| シーホネンス 受発注管理 最終版 | 既知欠陥2件を検出 | **high 3件を検出**（②欠落／宙に浮いた指示語／「標準化」の復活）＋「粒度」の未置換も検出 |
| 建匠 営業 4月版（旧型） | 多数 FAIL | **high 5件**（リテラシー／標準化／仮題なし／②③欠落／字数超過） |
| エスリード P2 0822修正版 | PASS | **PASS** |

1周目で3件のバグ（段落判定・訓練名の字数混入・CROSS の誤検出）が出たため修正し、
`eval/run_eval.sh` に **13ケースの回帰テスト**として固定した（現在 13/13 PASS）。
