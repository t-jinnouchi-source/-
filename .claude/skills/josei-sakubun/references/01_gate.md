# Gate｜起案前に埋める4点

本文を1文字も書く前に、この4ゲートを通す。
**埋まらない項目は「誰に・いつまでに・何を聞くか」を確定し、仮置きの値と `【未確定】` タグを付けて進む。黙って書き始めない。**

---

## Gate-A｜器を割る

### 埋める表

```markdown
## 器（YYYY-MM-DD 時点）
- コース名：
- 様式の版：              （例：R8.4版）
- 貼り付け先の欄：        （例：様式第1-3号 4欄「デジタル・DX化又はグリーン・カーボンニュートラル化の内容」）
- 記入枠の実測字数：      pt で 約   字 ／   pt で 約   字
- 目標字数：              〜   字（実測上限の 95〜97% に置く）
- 段落2・3の格納先：      □4欄に同居  □カリキュラム表の備考欄  □別紙  □【未確定】
- 出典：                  （様式実物のファイル名／URL／入手日）
```

### 社労士に投げる質問文（そのまま送れる形）

> お世話になっております。UX-HATCHの陣内です。
> ◯◯様の計画届につきまして、作文（訓練の必要性の説明）を作成するにあたり、
> 先に器を確定させたく、下記4点をご教示いただけますでしょうか。
>
> 1. 今回提出する様式の版と、作文を貼り付ける欄の正式名称・欄番号
> 2. その欄の記入枠に物理的に入る字数（想定されるフォントサイズもあわせて）
> 3. 訓練内容・習得技能の記述を、当該欄に同居させるか、カリキュラム表の備考欄／別紙に分けるか
> 4. 訓練実施計画届の提出予定日
>
> 字数と格納先が確定してから本文を書き起こしますので、
> 確定前の段階では仮の字数で下書きのみお送りする形になります。

### 注意点

- **「昨年と同じ欄」は根拠にならない。** 実際に、様式第1-1号19欄「事業展開等の内容と訓練の関連性」は R8.4版様式（欄は1〜18）に存在しない。旧称のまま会話すると社労士・労働局と噛み合わない。
- **記入枠は実測する。** 様式のセルに全角文字を流し込んで、はみ出す直前の字数を数える。フォントサイズを1段落とすと入る字数が2割前後変わる。
- **上限ぎりぎりに書かない。** 実測上限の 95〜97% を目標にする。清書時の体裁調整で数十字の余白が要る。

## Gate-B｜制度の鮮度を確認する

### 埋める表

```markdown
## 制度（YYYY-MM-DD 時点）
- 参照した支給要領の版・日付：
- 参照したパンフレットの版・日付：
- 直近の改正日：                    （起案日より前か／後か）
- 改正の要点（作文に効く部分）：
- 経過措置の有無：
- UX-HATCHと先方の 契約日／申込日／発注日：      → 旧基準で審査される可能性 □あり □なし □要確認
- Q&A の版：                        （更新が止まっている場合は根拠として弱いことを明記）
```

### 手順

1. **起案日と直近改正日を突き合わせる。** 改正直後（1〜2ヶ月以内）に書く場合は、パンフレットの該当ページを開いて注記の新設を確認する。前年の作文をベースにすると必ず取りこぼす。
2. **経過措置を最優先で確認する。** 事業内訓練では、経費に係る契約・申込・発注のいずれか1つが改正日以前に行われていれば、改正前の支給要領で審査される場合がある（附則1402ロ）。
   - **旧基準が使えるかどうかで、書き方の自由度が変わる。** 契約日の確認は最初の30分でやる。
   - 旧基準が使える場合は、日付・相手方・役務内容が分かる書類を計画届に添付する。
3. **民間記事・ブログを根拠にしない。** 支給要領・パンフレット・Q&A・活用事例集の一次資料に当たる。生成AI活用研修が認められた／認められなかった公式事例は存在しないため、押し切らず労働局照会を前提にする。

### 2026年8月3日改正（現行の判定軸）

- パンフレット P28 表1①② に「令和8年8月3日以降に提出する計画では、DX・GX化に関する訓練であっても対象外となります」という注記が新設された。
- 表1本文の文言自体は変わっていないが、**「DX研修だから対象」というルートが閉じた。**
- 判定軸は「**対象労働者の職務に直接関連する専門的な知識及び技能か**」の一点。
- 対応：支給要領0303ヘ(ロ)の3段構成（①会社がDX化を進める→②これに関連する業務に従事させる→③その上で必要な専門的な知識及び技能）を第1段落に文単位で充当する。**②を飛ばすと表1①で落ちる。**

### 時間数のリスク（必ず計算する）

- 1コースの実訓練時間数の**下限は10時間**。表1・表2に該当する部分は実訓練時間数に**算入されない**。
- 総時間が11〜12時間しかない案件で、最終回の数時間が丸ごと否認されると**下限割れ＝不支給**に直結する。
- したがって：
  - 最終回を「情報セキュリティ研修」と書かない。**部門ごとの業務行為**として書く（生成物の検証／取引先の確認事項への回答文書作成／情報が外部に渡った事例の要因分析／初動対応の記述）。
  - カリキュラムに「生成AIとは」「DX概論」「活用事例の紹介」の枠を**1コマも置かない**。
  - 開講式・閉講式・オリエンテーションは一の計画当たり累計60分まで。
  - 全講座に文章・図表による**教材が必須**（表2⑩）。
  - 実施場所は営業中の生産ライン等でないこと（表2⑦）。

## Gate-C｜先方の実呼称を取る

`references/04_hearing.md` の語彙表を埋める。

**ここを飛ばすと、最終版で一斉置換が発生する。** 実際に起きた置換：

| 起案時に書いた語 | 先方の実呼称 |
|---|---|
| 作業日報 | 報告書／作業報告 |
| 是正処置記録 | 日々の不良事項やエラー |
| 作業標準書 | 作業標準 |
| 粒度 | 細かさ |

置換は文字数を変えるので、**器ぎりぎりで書いていると本文の再設計になる。**

## Gate-D｜連年・重複を洗う

### 埋める表

```markdown
## 連年・重複（YYYY-MM-DD 時点）
- 同一事業主の過去の計画届：      □入手済み  □未入手（入手先：      ）
- 前年度の訓練名・実施期間・時間数：
- 前年度作文からの抽出禁止語（機械抽出）：   語 → 案件固有禁止語.txt に格納
- 前年度の区分（13欄／17欄）：
- 今年度の区分の案と理由：
- 同一受講者の年度内受講回数：       回目（年度内3回まで）
- 同時提出する他部門・他案件の作文：
```

### 手順

1. 過去の計画届 PDF を入手し、作文部分をテキスト化する。
2. **15字以上の連続一致**と**特徴語**を機械抽出し、`案件固有禁止語.txt` に落とす。
3. 区分を前年と変えるべきかを判定する → `references/05_renzoku.md`。
   - 「同じ区分・同じ実施機関・同じ受講者」の**三点一致**は、重複受講の疑義を自分から作る形になる。
4. 同時提出する他部門・他案件の作文を洗い出し、機械チェックの `--cross` に渡す。
