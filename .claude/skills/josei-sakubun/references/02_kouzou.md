# 構造｜3段構成のテンプレート

支給要領 **0303ヘ(ロ)** の3段構成を、**第1段落に文単位で充当する**のが現行（R8.8.3改正以降）の型。

---

## 全体設計

| 段落 | 字数配分 | 役割 |
|---|---|---|
| 第1段落 | 40〜45% | 0303ヘ(ロ) ①②③ ＋ 生じている事象 |
| 第2段落 | 35〜42% | 訓練内容（カリキュラム全項目を収容） |
| 第3段落 | 17〜21% | 訓練後に何が揃うか → 部門の業務にどう活きるか |

器が 580字なら 250字／230字／100字が目安。

---

## 第1段落｜4文で固定する

### 文の役割

```
第1文  ①事業主が進めるDX化の取組        主語＝当社
第2文  ②これに関連する業務に従事させる    主語＝人（担当者）  ← 最頻の欠落
第3文  生じている事象（課題）             主語＝事象
第4文  ③その上で必要な専門的知識及び技能   主語＝技能
```

### 文型テンプレート

**第1文（①会社のDX化）**
> 当社は〔経営方針の言葉／デジタルを前提とした事業運営への転換〕を進めており、〔部門〕が扱う〔対象物A〕〔対象物B〕〔対象物C〕を電子データとして整え、〔動作〕に生成AIを用いる運用へ移行しています。

- 「導入済み」と書かない。**「導入を進める」「移行しています」**で統一する。前年に「今後導入する計画」と書いていた場合、今年「導入済み」と書くと不整合になる。
- 業界一般論（「〜が求められています」「〜が激化しています」）から**書き出さない**。根拠を示せない一般論は、表1①の「間接的」という印象を第1文で与える。

**第2文（②対象労働者と従事業務）** ← **絶対に落とさない**
> 中でも〔部門〕の担当者は、〔業務A〕と〔業務B〕の作成に従事しています。

- 主語は**人**。「〜の業務があります」ではなく「担当者は〜に従事しています」。
- ここに書く業務が、**対象労働者一覧・雇用契約書と三者一致**する必要がある。
- **人数は本文に書かない**（様式第1-1号7欄・17欄の記載事項。本文と食い違うと修正になる）。

**第3文（生じている事象）**
> しかし、〔具体的な現象〕のため、〔結果として起きていること〕という状態になっています。

- 「属人化」「個人の経験や勘に依存」と書かない（§禁止語）。**現象そのものを描写**する。
  - ✗ 個人の裁量に委ねた属人的な手法が定着しており
  - ✅ 同じ内容を別の台帳へ書き写す作業が繰り返され、工程ごとの見方が社内間でそろわない

**第4文（③必要な専門的な知識及び技能）**
> そのため同担当者には、〔判断行為A〕し、〔判断行為B〕する専門的な知識及び技能の習得が必要です。

- **条文語「専門的な知識及び技能」を必ず使う。** 「スキル」「ノウハウ」「力」に置き換えない。
- 中身は**人の判断行為**に限定する。**成果物（自社の基準・マニュアル・体制）を作る話にしない。**
  - ✗ 記録の判定基準を自社で定め、手順として書き残し運用し続ける力
  - ✅ 記録様式に求められる記載事項を読み取り、記載すべき要素の細かさを判定して書き分ける専門的な知識及び技能

## 第2段落｜カリキュラム全項目を収容する

### 文型テンプレート（3文）

> 本研修では、仮題の〔題材A〕や〔題材B〕を題材として、〔カリキュラム①②③〕を学びます。
> あわせて、〔カリキュラム④⑤⑥〕を習得します。
> さらに、〔カリキュラム⑦⑧⑨⑩〕に関する専門的な知識及び技能を身につけます。

### ルール

1. **カリキュラム全項目を入れる。** 前半だけ書いて最終回を落とすと、総訓練時間と作文の記述範囲がずれ、落とした時間分が否認される導線になる。**総時間が10〜12時間の案件では下限割れ＝不支給に直結する。**
2. **講座番号・回数・時間数・人数を書かない。** カリキュラム表・時間割との突合で必ず修正が出る。
3. **カリキュラム表の項目名を鍵括弧で引用する場合は、表の表記と一字一句一致させる。**
4. **題材は「仮題の◯◯」と対象物側に冠する。**
5. **最終回（情報の取扱い系）は、部門固有の業務行為として書く。**
   - ✗ 情報セキュリティ研修／情報リテラシー／リスク管理の基礎
   - ✅ 営業＝提案資料を社外へ示す前の記載内容と出典の検証／取引先から届く情報の取扱いに関する照会への回答文書の作成
   - ✅ 工場＝つくった草案が記録として成立するかを確かめる手順／審査機関から届く記録の提供範囲に関する照会への回答文書の作成
   - ✅ 業務＝集計結果と帳票の突合による検証／取引先の年次の確認事項への回答文書の作成
6. 動詞を段落内で重複させない（「学び」「習得します」「身につけます」を1回ずつ）。

## 第3段落｜訓練後

### 文型テンプレート

> 結果として、〔揃うこと〕、〔できるようになること〕という知識及び技能を身につけ、〔部門〕の業務に活かします。

### ルール

- **成果を約束しない。** 「〜を実現します」「競争力を強化します」「生産性向上を実現します」は成果約束語。
- **主語は人の技能**に置く。「体制を確立します」「仕組みを構築します」は表1④に接触する。
  - ✗ 蓄積された営業情報を部門の資産として活用していく体制を確立します
  - ✅ 蓄積した営業情報を部門の資産として扱える知識及び技能を身につけ、営業部門の業務に活かします
- 着地は「〔部門〕の業務に活かします」または「〔部門〕の業務効率化とDX化に活かします」。

## 複数本を同時に出すとき（部門別・講座別）

3本以上を並べて読まれる前提で書く。**使い回しに見えた時点で疑義になる。**

| 分離軸 | やること |
|---|---|
| **対象物語** | 部門ごとに扱う帳票・対象物を排他にする。1語も混入させない（機械チェックの `CROSS` で検出） |
| **課題語** | 部門ごとに別の現象を書く。「担当者ごとにバラつく→揃える」を3本で使わない |
| **書き出し位置** | 第1文の主語となる対象を部門ごとに変える（営業＝営業が扱う情報／工場＝工場で生じる記録／業務＝様式の異なる帳票） |
| **接続句** | 「加えて／結果として」と「さらに/あわせて／これにより」を本数で振り分ける |
| **着地の指標** | 部門ごとに別の指標にする（記載品質の均一化／記法の統一／提案の型の蓄積） |

## 悪い型（2026年4月案件で多用。現行では使わない）

```
〔業界〕においては、〔一般論の課題〕が深刻な課題となっています。
当社においても、〔属人化・個人の経験や勘〕により〔工数〕がかかっています。
〜するためには、〔デジタル技術の活用〕が不可欠です。
本訓練では、〔生成AIの基礎知識〕と〔セキュリティリテラシー〕を習得します。
本訓練により、〔創出された時間〕を〔付加価値の高い業務〕に充てることで、
〔成約率の向上／競争力の強化〕が期待できます。
```

**この型が落ちる理由**：
- 業界一般論から入っている（表1①の「間接的」）
- ②対象労働者の特定がない
- 「基礎知識」「リテラシー」がR8.8.3で対象外と明記された語
- 「創出された時間」「成約率の向上」が成果約束語
- 社名を差し替えるだけで他社に使えてしまう＝**同一実施機関の複数申請で横断的に見られたときに崩れる**
