# Astra（ChatGPT）CLI 連携

「Astra」「アストラ」＝ **ChatGPT（OpenAI）の Astra**。DataStax Astra DB など同名の別製品ではない。
ユーザーの PC にインストールされた CLI 経由で使う。

## 1. 実行前チェック

1. CLI の存在確認
   - Mac / Linux：`command -v astra`
   - Windows（PowerShell）：`Get-Command astra`
   - コマンド名：`astra`（※実際のコマンド名が違う場合はここを書き換える）
2. 見つからない → **Claude が代わりに答えない。**「Astra CLI が見つからない」と報告して止まる。
3. 非対話（1回実行して結果を返す）モードの書き方が不明なら、`astra --help` で確認してから使う。

## 2. 依頼文を組み立てる

Astra は Claude との会話の文脈を知らない。**依頼文だけで完結する**ように次の4点を必ず入れる。

```
【目的】何のためにやるか（例：助成金作文の審査リスクを洗い出したい）
【前提】対象・背景・制約（例：人材開発支援助成金、様式第1-3号4欄、583字以内）
【依頼】具体的にやってほしいこと
【出力形式】箇条書き／表／文字数など
```

- 対象ファイルがあれば、パスを渡すか内容を貼る。
- 依頼文が長い・改行や記号を含む場合は、一時ファイルに書き出してから渡す（シェルのエスケープ事故を防ぐ）。

### 外部送信の注意
Astra への送信＝社外サービスへの送信。次を含む場合は **伏せ字にするか、送る前にユーザーに確認する。**
- 先方の社名・担当者名・受講者氏名
- 未公開の提案金額・契約条件

## 3. 結果の返し方

| ユーザーの言い方 | 返し方 |
|---|---|
| 「Astraで〜」「Astraに聞いて」 | ① Astra の回答（要点） ② Claude の補足（事実誤認・抜け漏れがあれば指摘。なければ省略） |
| 「Astraでも確認して」「Astraと比較」 | Claude 案と Astra 案を表で並べる → 差分 → **どちらを採用すべきか**を理由付きで示す |

- Astra の回答を Claude が書き換えて「Astra の回答」として出さない。要約する場合は要約だと明示する。

## 4. 失敗時

認証エラー／タイムアウト／レート制限などは、**エラーメッセージをそのまま示して、再実行するか・Claude が代わりにやるかを確認する。** 黙って Claude が代行しない。
